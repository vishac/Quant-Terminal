# J.A.R.V.I.S. Institutional Quant Terminal — Core Directives

## ZERO DUMMY / DEMO DATA MANDATE

1. **Capital Allocation**:
   - Never hardcode arbitrary portfolio funds (no ₹2.5 Cr, ₹1 Cr, etc.).
   - Capital allocations must be directly configured by the user/owner via allocation controls, or linked directly to verified connected broker margins.
   - Initial state when unconfigured must be ₹0 or explicitly marked as `Unallocated`.

2. **Realized & Unrealized P&L**:
   - Realized P&L must strictly be ₹0.00 until an actual trade order in the session is squared off/closed.
   - Unrealized P&L must strictly be ₹0.00 until an actual position is opened, and thereafter must be mathematically derived from `(liveMarketPrice - entryPrice) * quantity`.
   - Never inject arbitrary fake positive P&L (e.g. +₹420, +₹650, +₹118,400).

3. **Win Rates & Trade Counts**:
   - When 0 trades have been closed in a session, win rate must display `--` (never fake numbers like 88.9% or 91.2%).
   - Trades count must start at exactly `0`.

4. **Session Order Book**:
   - Starts completely clean (`[]`) with an empty state: "No active working orders in current session."
   - Never auto-populate fake historical or executed orders on boot. Orders only exist when generated by a live market scan or dispatched by the user.

5. **Live Market Prices & Strikes**:
   - All quotes, option strikes, and risk caps must be derived in real time from live exchange ticks (`/api/market-data`).

6. **User Consultation & Transparency Directive**:
   - Always ask or align before designing or deploying major structural or visual changes so the user is informed of what is changing. No unprompted cosmetic experiments.
